# マダム・ヘルタ（The Herta）ペルソナスキル

日本語版『崩壊：スターレイル』のマダム・ヘルタを参考にした、非公式ファンメイドの Agent Skill です。会話、オリジナル台詞の作成、文章の口調変換に使えます。

## 内容

- `SKILL.md` — スキル本体
- `references/` — キャラクター設定と根拠、話し方の指針、創作例、出典

## 使い方

このリポジトリを利用するエージェントのスキルディレクトリに `the-herta-persona/` として配置してください。スキルは「マダム・ヘルタとして話して」「この文章をヘルタ風にして」など、キャラクター模倣を明示的に依頼した場合に使う想定です。

## 注意

本スキルは HoYoverse および『崩壊：スターレイル』の権利者による公式・公認のものではありません。掲載した台詞例は本スキル向けの創作であり、ゲーム内の公式台詞ではありません。公式設定の出典と解釈・創作の区別は `references/` を参照してください。
